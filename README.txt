How to publish with GitHub Pages:
1. Open your GitHub repository (or create a new repository, e.g. mind-os-yulim).
2. Upload BOTH index.html and yulim_logo.png into the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait a minute or two and open the Pages URL shown on that screen.

Important:
- This is a prototype, not a connected AI counselor.
- It does not send the user's text to an AI service.
- Journal records are stored in the current browser using localStorage.
- Clearing browser data may erase records; use the export feature for a backup.
- Before public release, review privacy, security, accessibility, crisis guidance, and company authorization/branding.
